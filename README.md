## 关闭审查

按 issue 去重汇总候选，区分优先审查、需要补充确认和存在未完成事项。候选原因包括关闭引用 PR 已合并、失败清单已有处理结论、全部标记处理、重复主记录和剩余任务的明确转移。父子、来源和其他用例的相关引用单独展示，不据此生成关闭候选。

逐项区分通过、修复 PR 已合并、skip / xfail、测试删除替换、转移跟踪、删除线和未知；展示人工讨论、GitHub Actions nightly 和 PR 状态证据。删除线和 skip 不直接代表缺陷解决，标题声明数量不一致的清单保留覆盖未知，目标 release、间歇性失败与未完成反馈需单独确认。批次报告与底层遗留缺陷分开处理，页面不执行关闭操作。

审查视图可筛选、分享、撤销、排序和导出 CSV；详情中的用例与证据按批次展开。配置未核对的通过记录保持待确认；详情保留纯文本 workflow、run 编号、分支、commit 与评论记录标识，逐项摘录包含对应测试名。

## 桌面工作台

- 固定导航直达整体分布、矩阵、队列、清单和数据质量；图表可收起。
- 筛选器可搜索和多选，同维度 OR、不同维度 AND；支持浏览器后退/前进、撤销以及分享当前视图。
- 清单突出编号、标题、模块、负责人、目标版本、关闭引用 PR 和更新时间；详情提供测试入口、环境及原文证据。
- 整体分布按全部 issue 计算，矩阵支持数量和模块内占比，未知单独显示为中性灰。
- 负责人状态与阻塞证据分开；Unexpected success 为测试预期需核对；not implemented 不直接归类为新功能请求。
- 关闭引用 PR 与普通引用分开；代码块保留缩进复制，正文及评论按需展开，评论每批 20 条。
- 数据质量展示材料覆盖率、待定位分类与验证评论线索；人工更正保留核查人、日期和依据。

`index.html` 内嵌数据、样式、脚本，无外部 URL、资源、backlink 或运行时网络请求。下载该文件也可以离线查看。当前仅针对桌面使用优化。

## 重建与更新

需要 Python 3。使用已发布的地址清理快照重建：

```sh
python tools/update_report.py --cached data/source-snapshot.json --output-dir .
python tools/verify_report.py index.html data/source-snapshot.json
python -m unittest discover -s tools -p 'test_*.py'
```

获取最新快照还需要已登录的 GitHub CLI：

```sh
python tools/update_report.py --output-dir .
```

保存公开快照时，外部地址会被移除；GitHub issue / PR 引用保留为仓库名和编号，Actions 引用保留为运行编号，以支持无链接的证据重建。完整评论保留 Markdown，以解析结果表格和区分引用。PR 关联合并 issue 时间线与 PR 关闭引用的反向索引，并独立校验。

生成器、模板、规则、核查配置和检查脚本都在 `tools/`，详细说明见该目录 README。发布源为 `main` 分支根目录；提交新的 `index.html` 后 Pages 会重新部署。没有自动定时更新任务。

公开线索和自动分类不代替当前复现、根因定位或严重度判断。报告中的版本是报告环境；只有经人工核查的验证记录才作为已确认验证结果。
