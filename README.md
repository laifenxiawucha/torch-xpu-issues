面向维护仓库的程序员，提供整体 issue 分布、开发队列、搜索筛选、分页、公开证据和 CSV 导出。

当前数据快照：2026-10-14 13:15:30（北京时间），525 条未关闭 issue。页面是静态快照，数据不会自动更新。

`index.html` 内嵌全部数据、样式与脚本，无外部资源、外部链接或 backlink。直接下载 HTML 也可以离线使用。

## 发布与更新

GitHub Pages 从 `main` 分支根目录发布。更新报告后覆盖 `index.html` 并提交到 `main`，Pages 会重新部署。

本仓库保存报告页面；页面中的技术范围、影响类型和核查动作来自公开文本线索，不代表已确认根因或当前复现结果。

本版将发现渠道（UT / E2E / CI）与问题影响独立展示，并增加技术范围 × 问题类型矩阵。修复队列仅统计 GitHub 明确关闭引用的 PR，普通交叉引用保留在详情中。复现材料标记来自正文线索，报告版本与最近验证版本分别展示。

“分享当前筛选”保存搜索、筛选、排序、每页数量和页码到 URL 片段，打开链接可恢复；不会增加外部链接或页面网络请求。
